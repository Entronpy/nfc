# NFC 卡片内容定制网站

**分类：网站（web）**

“碰一碰”NFC 卡片内容定制工具。用于制作卡片内容和访问链接，并提供二维码及 NFC 写入指引。

## 页面与文件

| 文件 | 用途 |
|---|---|
| `index.html` | 网站主入口 |
| `link.html` | 链接页面 |
| `qr.html` | 二维码页面 |
| `transfer.html` | 内容转移页面 |
| `terms.html` | 使用条款 |
| `wx.html` | 微信相关页面 |
| `qrcode.min.js` | 二维码生成脚本 |
| `guide-*.jpg`、`write-demo.mp4`、`videos/` | 使用指引与演示资源 |

## 与个人名片仓库的区别

本仓库用于制作和定制 NFC 卡片内容；`card` 仓库用于展示 ColdFish 的个人名片。

## 当前访问地址

https://entronpy.github.io/nfc/

现有页面引用了该路径。仓库重命名时需同步处理网站发布路径与已有 NFC 标签的访问兼容。
